# Operating System Concepts

## Mutual Exclusion
A mutex prevents simultaneous modification of shared equipment state.

## Critical Section
Equipment availability checking and database updates are protected.

## Resource Allocation
Equipment is allocated only when available.

## Synchronization
Returns and waiting requests are coordinated with resource availability.

## FCFS Queue
Unavailable equipment requests enter a First Come First Served queue.

## Process Management
Authentication, allocation, return and queue handling are separated into application modules.
